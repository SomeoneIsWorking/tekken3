# RE frontier

1. Select the target disc region and record the executable name, serial, hash, entry, load address,
   and text extent from the real image.
2. Provision the disc through `.env` and drop-in resolution without tracking copyrighted data.
3. Bring up a deterministic psxport/oracle boot harness and prove it can report both agreement and
   disagreement.
4. Recompile to the first real divergence, then proceed bottom-up.
5. Identify camera state and graphics submitters from game code before creating native producers.
6. Enable widescreen only on owned camera/projection paths.
7. Enable interpolation only for transforms computed by PC-native producers.
